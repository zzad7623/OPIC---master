# 🎙️ OPIc AI Master (스마트폰 오픽 실전 훈련기)

실제 오픽(OPIc) 시험 환경을 완벽하게 재현하고, 스마트폰을 들고 다니면서 언제 어디서나 **무한 랜덤 질문 답변 훈련** 및 **15문항 실전 모의고사**를 볼 수 있는 AI 오픽 트레이너입니다.

---

## ✨ 핵심 기능

1. **🎲 무한 랜덤 질문 훈련 모드**:
   - 누를 때마다 서베이(음악, 공원, 여행, 집 휴가 등), 돌발(은행, 재활용 등), 롤플레이(11번 질문, 12번 문제해결) 중 질문이 끊임없이 랜덤 출제됩니다.
   - 실제 시험처럼 가상 시험관 **Ava의 음성**으로 질문이 나오고, **1회 다시 듣기(Replay)**를 지원합니다.
2. **📝 실전 15문항 모의고사 모드**:
   - 1번 자기소개부터 15번 심화 이슈까지 실제 시험 순서 및 콤보 세트로 실전처럼 테스트합니다.
3. **🎙️ 스마트폰 음성 인식 (STT) & 내 발화 다시 듣기**:
   - 스마트폰 마이크로 답변하면 실시간으로 텍스트로 받아 적어줍니다.
   - 내가 녹음한 목소리를 직접 다시 들어보며 억양과 발음을 체크할 수 있습니다.
   - *(지하철, 도서관 등 소리 내기 어려운 곳에서는 직접 텍스트 타이핑으로도 연습 가능!)*
4. **🤖 Gemini AI 실시간 IM 맞춤 피드백**:
   - **예상 등급 판정** (IL, IM1, IM2, IM3, IH)
   - **과거 시제(Past Tense) 집중 점검**: IM 취득의 최대 난관인 과거 시제(went, played, enjoyed) 실수 철저 분석
   - **문법 및 어휘 교정**: 주어-동사 수일치 및 어색한 콩글리시 교정
   - **필러(Filler Words) 추천**: `You know`, `Actually`, `To be honest` 등 끊김 없는 발화를 위한 표현 제안
   - **IM 맞춤 모범 답변 (Model Answer)**: 외우기 쉽고 입에 착 붙는 자연스러운 모범 스크립트 제공 (음성 듣기 지원)
5. **📋 서베이(Background Survey) 황금 추천 1초 세팅**:
   - 점수 따기 가장 쉬운 **'황금 12개 서베이 조합'** 원클릭 적용 및 체크박스 커스텀 설정 지원.
6. **📚 복습 & 오답 노트**:
   - 연습한 모든 답변과 AI 피드백이 브라우저에 자동 저장되어 이동 중 복습 가능.

---

## 🚀 실행 방법

### 방법 1. PC에서 바로 실행 (가장 간단)
1. `run.bat` 파일을 더블 클릭합니다.
2. 브라우저가 자동으로 열리며 프로그램이 시작됩니다! (`http://localhost:8080`)

---

### 방법 2. 스마트폰에서 접속하기 (집 안 Wi-Fi)
1. PC에서 `run.bat`을 실행합니다.
2. 터미널 창에 뜨는 **📱 스마트폰 브라우저 접속 주소** (예: `http://192.168.0.15:8080`)를 스마트폰(사파리 또는 크롬) 주소창에 입력합니다.
   *(※ 스마트폰과 PC가 같은 집 Wi-Fi에 연결되어 있어야 합니다.)*
3. **스마트폰 '홈 화면에 추가'**를 누르면 앱스토어에서 받은 앱처럼 바탕화면에 아이콘이 생성됩니다!

---

### 방법 3. 밖에서도 스마트폰으로 평생 무료 사용하기 (추천 ★)
컴퓨터를 켜두지 않고 **지하철, 카페, 회사 등 밖에서도 스마트폰으로 언제든 접속**하려면, 완전 무료 호스팅 사이트에 1분 만에 올릴 수 있습니다.

#### [Vercel 무료 배포 (1분 완료)]
1. [Vercel](https://vercel.com) 사이트에 무료 가입합니다.
2. 이 `영어학습` 폴더를 GitHub 저장소에 올리거나, Vercel 대시보드에서 프로젝트를 업로드(Deploy)합니다.
3. 생성된 나만의 무료 웹 링크(예: `https://my-opic.vercel.app`)를 스마트폰에 즐겨찾기 또는 홈 화면에 추가하면 끝!

## 🔑 Gemini API 키 발급 방법 (100% 무료)
AI 실시간 첨삭 기능을 200% 활용하시려면 구글 무료 API 키를 등록하세요:
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 구글 계정으로 로그인합니다.
2. **"Create API key"** 버튼을 누릅니다.
3. 생성된 키를 복사하여, 앱 상단의 **[⚙️ 설정] -> [Gemini API Key]**에 붙여넣고 저장하세요.
*(※ API 키 없이도 내장된 스마트 채점 알고리즘과 모범 답안으로 바로 연습이 가능합니다.)*

## 💡 오픽 IM 등급 달성을 위한 3대 핵심 꿀팁
1. **과거 시제를 사수하라**:
   - 오픽 채점관이 IM과 IL을 가르는 1순위 기준은 과거 경험 질문에서 `went`, `saw`, `was`, `had` 등 **과거 시제를 일관되게 쓰는가**입니다.
2. **침묵(Pause)을 필러로 메워라**:
   - 할 말이 생각나지 않을 때 한국어로 "음..." 하지 마시고, `Well...`, `You know...`, `Actually...`, `Let me see...`를 소리 내어 말하세요.
3. **서베이 주제를 엮어라**:
   - 공원 가기, 조깅, 걷기, 자전거 타기는 모두 *"집 근처 공원에 편한 옷 입고 가서 음악 들으며 한다"*는 하나의 틀로 돌려막기가 가능합니다!
